gopower-z

powerz is a read-only Go CLI and library for the ChargerLAB POWER-Z KM003C USB-C power meter. It is built to be driven by people and by AI agents: JSON output, structured errors, stable exit codes, and a self-describing schema.

go install github.com/ljagiello/gopower-z/cmd/powerz@latest   # needs libusb + pkg-config
powerz measure -duration 10s
