Measure USB‑C power from the command line.

powerz is a read-only CLI and Go library for the ChargerLAB POWER-Z KM003C. Piped output is JSON with units in the field names, errors have stable exit codes, and powerz schema describes the whole interface, so scripts and AI agents can drive the meter as easily as you can.

brew install libusb pkgconf
go install github.com/ljagiello/gopower-z/cmd/powerz@latest
sudo apt install libusb-1.0-0-dev pkg-config

Commands

On a terminal, plain powerz opens a live dashboard. Piped, it prints one JSON reading. Every command below has a fixed output shape.

powerz read
One snapshot: VBUS, IBUS, power, temperature, CC and D+/D− lines.
powerz measure --duration 10s
Min, mean, max and percentiles of V, A and W, the shape over time in bins, when the current changed, plus Wh, mAh and the USB-PD contract.
powerz log --format csv
A stream of snapshots as JSON lines or CSV.
powerz pd --duration 30s
Decoded USB Power Delivery messages, then a summary line.
powerz info
Model, firmware and hardware versions, serial, settings.
powerz schema
Every command, flag, field and exit code, as JSON, for agents.

All commands and flags

Read-only by design

Every frame is checked against a whitelist right before it goes to the meter, and a fuzz test proves the whitelist accepts nothing else. powerz cannot change the voltage on the bus.

Sent

  • GET_DATA for ADC, settings and the PD buffer
  • CONNECT and DISCONNECT
  • MemoryRead of three fixed 64-byte information blocks

Never sent

  • Settings writes and factory reset
  • Firmware and DFU commands
  • Authentication and stream control
  • CDC text commands that make a charger raise VBUS
